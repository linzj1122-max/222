# Ozon 排名采集器

此 Chrome 扩展只读取 Ozon 搜索页中 MPStats 插件已经显示的搜索排名、SKU、价格、库存、30 天订单量、30 天销售额、评分和评价数，并发送到运营控制中心；它不会向 Ozon 店铺写入或修改任何数据。

## 安装

1. Chrome 打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`chrome-extension/ozon-ranking-collector`。

## 首次连接

1. 登录运营控制中心，进入“关键词排名”。
2. 点击“生成连接 Token”，网页会复制一段 JSON 配置。
3. 打开扩展，点击“粘贴配置”。

## 采集

1. 在扩展中输入俄语关键词和自己的 Product ID；系统会自动匹配已配置的 Ozon 账号，不需要选择店铺。
2. 点击“打开全站搜索”。
3. 等待 Ozon 页面中的 MPStats 搜索结果表出现。
4. 再次打开扩展，点击“采集并发送到控制中心”。
5. 回到控制中心输入同一个关键词，点击“读取最新 Top 100”。

连接 Token 只允许上传 Ozon 排名快照，有效期为 90 天；不要发送给其他人。
