# Ozon 标签采集器

这是与“Ozon 排名采集器”完全分开的独立 Chrome 扩展。它读取关键词搜索结果前 50 个商品链接，并只提取商品详情页中“Характеристики”上方的蓝色 `#标签` 区域。

## 品牌过滤

采集器优先从商品页的 Product 结构化数据读取品牌，然后删除：

- 与品牌完全相同的标签，例如 `#xiaomi`、`#tokonari`；
- 以下划线包含品牌词的标签，例如 `#наушники_xiaomi`。

被过滤的品牌标签不会进入高频统计或复制内容。

## 安装与使用

1. Chrome 打开 `chrome://extensions`，启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本目录 `chrome-extension/ozon-hashtag-collector`。
3. 在控制中心“关键词排名”中生成连接 Token 并复制配置。
4. 打开本扩展，点击“粘贴配置”，填写俄语关键词。
5. 打开关键词搜索页并等待商品加载，然后点击“抓取 Top 50 蓝色标签”。

原来的 `ozon-ranking-collector` 不需要修改，也不会被本扩展覆盖。
